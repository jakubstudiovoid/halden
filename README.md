# Halden

Prémiový web advokátní kanceláře. Tmavý základ, světlý režim, jeden grotesk, obsah na jednom místě.

## Obsah

Veškeré texty, lidé, oblasti a poznámky jsou v [src/content/site.ts](src/content/site.ts). Kontaktní e-mail se mění tamtéž.

Formulář údaje ověří a neukládá. Až bude ostrá schránka, napojí se v `src/lib/inquiry.ts` — bez změny zbytku webu.

## Režim a cookies

Tmavý režim je výchozí. Volba i souhlas s cookies zůstávají v prohlížeči. Měření je místní počítadlo, žádná třetí strana.
